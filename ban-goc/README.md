# Mộc Music

Website bán nhạc cụ dành cho đồ án, được xây dựng bằng HTML, CSS và JavaScript thuần.

## Cách chạy

Mở file `index.html` bằng trình duyệt, hoặc chạy một máy chủ web đơn giản trong thư mục dự án.

## Chức năng

- Trang chủ và danh mục nhạc cụ
- Danh sách, tìm kiếm, lọc và sắp xếp sản phẩm
- Xem chi tiết sản phẩm
- Giỏ hàng tự lưu trên trình duyệt
- Thanh toán và tạo đơn hàng mô phỏng
- Đăng ký, đăng nhập và xem lịch sử đơn hàng mô phỏng
- Trang quản trị tổng quan
- Giao diện tương thích máy tính và điện thoại

Toàn bộ dữ liệu trong bản demo được lưu bằng `localStorage`, chưa kết nối cơ sở dữ liệu hoặc cổng thanh toán thật.
